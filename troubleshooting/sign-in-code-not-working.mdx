---
title: "Sign-in code not working"
description: "The code was rejected, said it had expired, or never arrived. The causes and the fix for each."
---

When you sign in, Rivet emails a 6-digit code and you type it into the
screen you're signing in on. If the code isn't accepted, one of these
things happened.

## 1. The code expired

A code works for one hour. If you asked for it last night and came back
to it this morning, the app tells you it has expired.

**Fix:** On the code screen, tap **Resend code**. Rivet emails a new one.
Use the code from the newest email.

## 2. You're using an older code

Each time you ask for a code, the earlier one stops working. If you
requested two or three, the code from the newest email is the only one
that counts.

**Fix:** Open the most recent email, with the subject **Your Rivet
code** followed by the code, and type that one.

## 3. A digit was mistyped

The app says the code isn't right. Check each digit against the email.
On an iPhone, the code is usually offered above the keyboard, so you can
tap it instead of typing it.

**Fix:** Retype the code from the email, or tap **Resend code** and
start with a fresh one.

## 4. You asked for codes on two devices

Type the code on the screen where you asked for it. You can read the
email anywhere, so reading it on your phone and typing it on your
computer works. Asking for a second code on your phone after starting on
your computer gives you two codes, and only the newest one works.

**Fix:** Pick the device you want to use Rivet on, ask for the code
there, and type the newest code on that same screen.

## 5. The email hasn't arrived

Give it a couple of minutes, then check spam or junk and search your
mailbox for `Rivet`. Work email systems sometimes hold messages for a
while. If it's in spam, mark it as not spam so the next one lands in
your inbox.

If it still isn't there, tap **Resend code**.

## What if I still can't sign in?

Email **hello@getrivet.ca** with:

- The email address on your Rivet account
- The device you're trying to sign in on (iPhone, Android, MacBook, etc.)
- A screenshot of what you see on the code screen

We'll help you get in.
