---
title: "Can't log in"
description: "Sign-in code not arriving, wrong email, or an account that's been paused — how to tell which one and what to do."
---

Rivet doesn't use passwords. You sign in by entering your email; Rivet
emails a 6-digit code to that address; you type the code into the same
screen on the same device. If that loop is broken, one of three things
is happening.

## 1. The code isn't arriving

The most common cause. The email is in spam or the promotions tab.

<Steps>
  <Step title="Check spam and promotions">
    Give it a couple of minutes first. Then search your mailbox for
    `Rivet` across all folders. The subject reads **Your Rivet code**
    followed by the code. Work email systems sometimes hold messages
    for a while.
  </Step>
  <Step title="Mark it Not Spam">
    Once you find it, move it to your inbox and mark it as Not Spam (Gmail)
    or Not Junk (Outlook). Future Rivet emails will route correctly.
  </Step>
  <Step title="Resend the code">
    If it's genuinely not there, tap **Resend code** on the code screen.
    Use the code from the newest email.
  </Step>
</Steps>

<Note>
  A code works for one hour. If you asked for one yesterday and came
  back to it today, tap **Resend code** and use the new one.
</Note>

## 2. You're typing the wrong email

Rivet sends the code to the address attached to your account — not a
similar one. If the address has no Rivet account, the app tells you
there's no Rivet account for that address yet and emails a link to set
one up. Check the email you used at signup:

- Was it your professional address or a personal one?
- Did you include a typo (`.con` instead of `.com`, missing letter)?
- Is it the email your welcome message came to? That's the one Rivet
  knows about.

If you signed up with the wrong address by mistake, email
**hello@getrivet.ca** with both addresses (the one you used and the one
you want) and we'll move your account over.

## 3. Your account is paused

Accounts get paused for two reasons:

- **Trial expired and no card on file.** Your data is intact, but the
  app shows a "Subscribe to continue" overlay instead of the inbox.
  Subscribe via the payment link in the overlay (or in the
  expiry email we sent) and the overlay clears within a minute.
- **Manual hold.** Rare — happens if we flag suspicious activity on a
  new account. Email **hello@getrivet.ca** and we'll explain what
  triggered it.

In both cases the code still arrives and still works — you'll just
land on the overlay instead of the inbox.

## How sign-in works

There is **no password reset.** Rivet doesn't have passwords. Every
sign-in is a fresh code sent to your email. If you've forgotten which
email you used, that's the question to ask — not "how do I reset my
password."

Codes arrive by email only. Rivet never texts you a sign-in code. If a
page or a message asks you for a code we didn't email you, it isn't
Rivet.
